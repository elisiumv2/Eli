# Elisium asset pack

Extract the ZIP, then upload everything inside this folder to a public GitHub repository. Keep the folders and file names as they are. Upload the extracted files, not just the ZIP.

Send the repository link after uploading. Elisium can then be updated to download and cache these files instead of storing them inside the script.

This pack contains 59 UI icons, 6 weather textures, the menu background, the companion image and 8 texture-pack configs. The manifest maps each asset to its file path and includes file sizes and SHA-256 hashes. Icon aliases and texture-pack names are included.

The images are the original PNG bytes from the script. Texture-pack configs keep their existing Roblox IDs and external media links; those external files are not bundled here.

The current Elisium script has not been changed to use this pack yet. It will keep working until the GitHub link is connected.
